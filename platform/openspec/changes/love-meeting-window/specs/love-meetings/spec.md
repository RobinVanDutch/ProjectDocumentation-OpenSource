# Spec Delta

## Purpose

Клик по встрече в разделе «Встречи» MUST открывать окно встречи, а не окно календарного события:
у встречи другой набор полей и другой документ-владелец. Дельта фиксирует состав окна по макету
`Love/Meeting window (overlay)`, правило выбора окна через резолвер карточки и требование писать
правки в серию, а не во вхождение.

## ADDED Requirements

### Requirement: Встреча открывается своим окном

Событие, у которого есть миксин `MeetingEventLink`, MUST открываться окном `EditMeeting` из любого
места календаря (сетка дня, неделя, месяц, список дня). Заголовок окна MUST быть «Настройки встречи»
(`love.string.MeetingSettings`). Событие без этого миксина MUST продолжать открываться окном события
`EditEvent`.

#### Scenario: Клик по встрече во вкладке «Встречи»

- **WHEN** пользователь открывает вкладку «Встречи», переключает представление «Календарь» и кликает
  по встрече
- **THEN** открывается модальное окно с заголовком «НАСТРОЙКИ ВСТРЕЧИ» и затемнением под ним

#### Scenario: Клик по обычному событию календаря

- **WHEN** пользователь кликает по событию, у которого нет миксина встречи
- **THEN** открывается прежнее окно события с заголовком «СОБЫТИЕ»; поведение не изменилось

### Requirement: Состав окна встречи соответствует макету

Окно MUST содержать секции **О встрече**, **Когда**, **Где**, **Участники**, **Напоминания**
в указанном порядке и MUST NOT содержать строк «Местоположение» и «Видимость»: у встречи вместо
местоположения есть комната, а роль видимости играют тип, группа и приватность.

#### Scenario: Секция «О встрече»

- **WHEN** окно открыто владельцем
- **THEN** видны строки «Название» (`TextInput`), «Описание» (`TextArea` высотой в две строки),
  «Группа встреч» (`Dropdown`, строка отсутствует, если групп нет) и «Тип» со значением
  «Разовая встреча» или «Регулярная встреча»

#### Scenario: Секция «Когда»

- **WHEN** встреча повторяющаяся
- **THEN** в секции есть «Весь день» с иконкой-подсказкой, «Дата» (два поля начала и конца),
  «Часовой пояс» и «Повторять каждые» (число + единица) с подписью «Следующая встреча: …»
  под строкой; у разовой встречи строки повтора нет

#### Scenario: Секция «Где»

- **WHEN** окно открыто
- **THEN** видны «Переговорная» (`Dropdown` комнат офиса) и, у повторяющейся встречи,
  «Отображение в календаре» (`Toggle`)

### Requirement: Правки сохраняются в серию

Окно MUST писать изменения в мастер-событие серии (`calendar.class.ReccuringEvent`), найденное по
`calendar` и `eventId === recurringEventId`. Запись во вхождение (`ReccuringInstance`) MUST NOT
использоваться: календарь и список читают серию, поэтому такая правка не видна.

#### Scenario: Переименование встречи

- **WHEN** пользователь меняет «Название» и нажимает «Сохранить»
- **THEN** окно закрывается, новое название появляется в списке и календаре раздела «Встречи»,
  и открытие окна заново показывает это же название

### Requirement: Окно встречи использует UI Kit

Поля и переключатели окна MUST быть контролами `@hcengineering/ui/kit` (`TextInput`, `TextArea`,
`DateSelect`, `Dropdown`, `Toggle`, `NumberInput`, `MenuButton`, `Chip`, `Section`, `SettingRow`),
а не legacy-контролами календаря. Поле строки MUST занимать 12rem и прижиматься к правому краю,
растягиваемые поля MUST использовать модификатор на всю ширину.

#### Scenario: Строка «Часовой пояс»

- **WHEN** окно открыто
- **THEN** значение часового пояса показано вторичной кнопкой с шевроном на всю ширину колонки поля,
  по клику открывается выбор часового пояса

### Requirement: Подписи окна существуют во всех локалях

Каждая подпись окна MUST быть объявлена как `IntlString` в наборе строк своего плагина и MUST иметь
перевод во всех локалях пакета (`en`, `ru`, `de`, `es`, `fr`, `it`, `ja`, `pt`, `pt-br`, `tr`, `zh`, `cs`).
Строка, объявленная только в файле переводов, MUST NOT считаться достаточной: в разметке она даёт
`undefined`.

#### Scenario: Открытие окна после смены локали

- **WHEN** пользователь переключает язык на русский и открывает встречу
- **THEN** все подписи окна читаются по-русски, ни одна строка не содержит `undefined`
