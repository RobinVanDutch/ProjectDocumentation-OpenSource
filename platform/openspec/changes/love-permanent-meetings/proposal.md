# Proposal

## Why

Раздел «Постоянные встречи» сейчас работает как «комната без расписания»: `CreatePermanentMeetingPopup` спрашивает
только название, тип, запись/транскрипцию и участников. Нельзя задать дату/время, регулярность, напоминание, пароль
и комнату — за ними надо идти в разные места (`MeetingLinkPopup`, миксин события). Гостевую ссылку из таблицы не
скопировать, в таблице нет ни действий, ни группировки, удалить встречу можно только в обход раздела, а правила
«создатель удаляет, остальные выходят» нигде не выражены.

Владелец сформулировал целевую модель одним списком (2026-11-06): «постоянная встреча» — это полноценная встреча
со своим расписанием, комнатой, ссылкой, паролем и участниками; всё это заводится и правится из одного окна,
а таблица раздела даёт копирование ссылки, удаление и группировку с перетаскиванием.

## What Changes

1. **Одна модалка создания/настройки.** В `CreatePermanentMeetingPopup` (и в настройках существующей встречи) —
   название, дата и время, регулярность (частота/интервал/окончание), участники, напоминание («за N минут»),
   пароль для гостей, комната.
2. **Создание = расписание + постоянная встреча.** Модалка создаёт серию события (`rules` из п.1) с миксином
   `MeetingEventLink` и связанную `PermanentMeeting` (`permanentMeeting`), чтобы работали и вхождения, и постоянная
   комната. Сразу после создания показывается гостевая ссылка с кнопкой копирования.
3. **Таблица «Постоянные встречи».** Колонки: название, дата/время следующего вхождения, участники, действия.
   Действия в строке: «Копировать гостевую ссылку», «Настройки», «Удалить» (только создателю).
4. **Карточка постоянной встречи** открывает экран встречи; в правой панели — отметка «Постоянная встреча»,
   по нажатию открываются те же настройки, что в п.1.
5. **Вкладка «Встречи»** показывает все встречи — серии и одиночные. У регулярной встречи настройки — тот же набор
   из п.1.
6. **Режим правки вхождения** — только «Текущая» и «Все (будущие)» (штатный календарный выбор сокращается до двух).
7. **Права:** удалять может только создатель; остальные — только «Покинуть». Создатель покинуть встречу не может,
   только удалить.
8. **Группы.** Выделение нескольких встреч в таблице → «Объединить в группу» с названием; группы и встречи внутри
   переставляются перетаскиванием (порядок сохраняется).

## Capabilities

### New Capabilities

- `love-permanent-meetings`: модалка создания/настройки, состав данных (дата/время, регулярность, участники,
  напоминание, пароль, комната), создание серии + постоянной встречи, гостевая ссылка, таблица с действиями,
  карточка и вкладка «Встречи».
- `love-permanent-meetings-groups`: группы встреч, объединение выделенных, переименование, перетаскивание групп
  и встреч, сохранение порядка.
- `love-meeting-permissions`: кто удаляет, кто покидает, запрет «покинуть» для создателя, серверная проверка.

## Impact

- Модель: `models/love/src/index.ts` — новые атрибуты `PermanentMeeting` (напоминание, группа, порядок, пароль-флаг),
  новый класс группы; миграция для существующих воркспейсов.
- Клиент: `plugins/love-resources/src/components/CreatePermanentMeetingPopup.svelte` (переписать в общую форму),
  новый `EditPermanentMeetingSettings.svelte`, `PermanentMeetingPresenter`/таблица (`TablePermanentMeetings`
  во `models/love`), `Hall.svelte` (модалка группы, действия), `index.ts` (действия), `utils.ts`
  (`createPermanentMeeting` → создать серию + встречу).
- Календарь: `plugins/calendar-resources/src/components/UpdateRecInstancePopup.svelte` — ограничение режимов для встреч.
- Сервер: `server-plugins/love-resources/src/index.ts` — запрет снятия создателя из `owners`, завершение сессий
  при удалении (уже есть), проверка «удалять может только создатель».
- Локализация: 12 языков `plugins/love-assets/lang/*.json`.
- Тесты: unit на создание (серия + встреча + ссылка), права, порядок групп; e2e/Playwright-проверка на стенде.
- Документация: `docs/love.md` (§2.6, §7a), `docs/features/office-meetings.md`, Storybook-экраны.

## Не входит

- Перенос вхождения на новое время (override) — отдельная итерация (`love-meetings-pr428-gaps`, группа 2).
- Права владельца воркспейса на ссылку — по-прежнему нет.
