# Spec Delta

## Purpose

Группы постоянных встреч: объединение выделенных, название, порядок групп и встреч, сохранение порядка.

## ADDED Requirements

### Requirement: Объединение выделенных встреч в группу

Выделение нескольких встреч в таблице MUST давать действие «Объединить в группу» с вводом названия; по сохранению
создаётся группа, и выбранные встречи переезжают в неё.

#### Scenario: Объединили две встречи

- **WHEN** пользователь выделяет две встречи и выбирает «Объединить в группу», вводит название
- **THEN** в таблице появляется группа с этим названием и обеими встречами

#### Scenario: Пустое название

- **WHEN** название не введено
- **THEN** кнопка сохранения недоступна, группа не создаётся

### Requirement: Группа переименовывается и удаляется

У группы MUST быть действие переименования; при удалении группы встречи MUST оставаться и возвращаться в общий
список без группы.

#### Scenario: Переименование

- **WHEN** пользователь меняет название группы
- **THEN** новое название видно в таблице сразу и сохраняется

#### Scenario: Удаление группы

- **WHEN** пользователь удаляет группу
- **THEN** встречи группы остаются в таблице в разделе без группы

### Requirement: Перетаскивание меняет порядок

Порядок групп MUST меняться перетаскиванием; встречи MUST перетаскиваться между группами и внутри группы. Порядок
MUST сохраняться между сессиями.

#### Scenario: Переставили группы

- **WHEN** пользователь перетаскивает группу выше другой
- **THEN** порядок групп сохраняется и восстанавливается при следующем открытии раздела

#### Scenario: Перенесли встречу в другую группу

- **WHEN** пользователь перетаскивает встречу из одной группы в другую
- **THEN** встреча появляется в целевой группе на позиции, куда её отпустили, и порядок сохраняется

### Requirement: Сортировка по умолчанию — порядок групп и встреч

Таблица MUST по умолчанию показывать группы по их порядку, а встречи внутри — по своему; другие сортировки
временные и не меняют сохранённый порядок.

#### Scenario: Другая сортировка

- **WHEN** пользователь сортирует по названию
- **THEN** список перестраивается, но после сброса сортировки возвращается сохранённый порядок
