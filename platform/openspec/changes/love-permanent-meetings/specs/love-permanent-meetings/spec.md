# Spec Delta

## Purpose

Создание и настройка постоянной встречи одним окном, её представление в таблице, карточке и во вкладке «Встречи»,
а также гостевая ссылка.

## ADDED Requirements

### Requirement: Одно окно создания и настройки

Настройка постоянной встречи MUST задаваться в одном окне: название, дата и время, регулярность, участники,
напоминание, пароль для гостей, комната. Тот же набор полей используется при правке существующей встречи.

#### Scenario: Создание из раздела «Постоянные встречи»

- **WHEN** пользователь нажимает «Новая встреча»
- **THEN** открывается окно с полями: название, дата/время, регулярность, участники, «напомнить за N минут»,
  пароль для гостей, комната

#### Scenario: Правка существующей встречи

- **WHEN** пользователь открывает настройки встречи из строки таблицы или из карточки
- **THEN** открывается то же окно, заполненное текущими значениями, и сохранение применяет изменения

### Requirement: Регулярность задаётся правилом расписания

Регулярность MUST задаваться периодом (день/неделя/месяц + интервал) и необязательным окончанием; из неё строится
правило серии, по которому открываются вхождения.

#### Scenario: Еженедельная встреча

- **WHEN** пользователь выбирает «каждую неделю», 2 и окончание «до 31.12»
- **THEN** созданная серия имеет правило с интервалом 2 недели и датой окончания, вхождения видны в календаре

#### Scenario: Без регулярности

- **WHEN** пользователь не выбрал регулярность
- **THEN** создаётся одно вхождение на указанные дату/время и постоянная комната встречи

### Requirement: Создание даёт расписание и постоянную комнату

По сохранению MUST создаваться серия события с миксином `MeetingEventLink` и связанная постоянная встреча
(`permanentMeeting`), чтобы работали и вхождения по расписанию, и постоянная комната.

#### Scenario: Встреча создана

- **WHEN** пользователь сохраняет окно создания
- **THEN** в календаре появляется серия с выбранным правилом, во вкладке «Постоянные встречи» — встреча,
  связанная с серией, комната и настройки перенесены из окна

### Requirement: Гостевая ссылка доступна сразу

После создания MUST показываться гостевая ссылка с кнопкой копирования. Ссылка MUST копироваться и из строки
таблицы действием «Копировать ссылку» (только участнику встречи).

#### Scenario: Ссылка после создания

- **WHEN** встреча создана
- **THEN** показывается ссылка вида `<front>/meetings/<shortId>` и кнопка «Копировать»

#### Scenario: Копирование из таблицы

- **WHEN** участник нажимает «Копировать ссылку» в строке встречи
- **THEN** ссылка кладётся в буфер обмена, а строки с ошибкой не появляется

### Requirement: Таблица постоянных встреч с действиями

Таблица «Постоянные встречи» MUST показывать название, дату/время следующего вхождения, участников и действия
строки: «Копировать ссылку», «Настройки», «Удалить» (последнее — только создателю).

#### Scenario: Строка встречи

- **WHEN** пользователь открывает раздел «Постоянные встречи»
- **THEN** в каждой строке рядом с названием есть кнопка копирования ссылки, а в действиях — настройки;
  удаление видно только создателю

### Requirement: Карточка постоянной встречи

Карточка MUST открывать экран встречи, а в правой панели MUST быть отметка «Постоянная встреча», по нажатию которой
открывается окно настроек из первого требования.

#### Scenario: Открытие карточки

- **WHEN** пользователь открывает встречу из таблицы
- **THEN** показывается экран встречи, в правой панели — отмеченный пункт «Постоянная встреча»

#### Scenario: Настройки из карточки

- **WHEN** пользователь нажимает отметку «Постоянная встреча»
- **THEN** открывается окно настроек с текущими значениями

### Requirement: Вкладка «Встречи» показывает все встречи

Вкладка «Встречи» MUST показывать и регулярные серии, и одиночные встречи; настройки регулярной открывают тот же
набор полей, что и создание.

#### Scenario: Регулярная встреча во вкладке

- **WHEN** пользователь открывает регулярную встречу из вкладки «Встречи»
- **THEN** доступна настройка с датой/временем, регулярностью, участниками, напоминанием, паролем и комнатой

### Requirement: Правка вхождения — только «текущая» и «все будущие»

При изменении вхождения регулярной встречи MUST предлагаться только варианты «Текущая» и «Все (будущие)».

#### Scenario: Перенос одной встречи

- **WHEN** пользователь меняет время вхождения
- **THEN** окно предлагает «Текущая» и «Все (будущие)», других вариантов нет
