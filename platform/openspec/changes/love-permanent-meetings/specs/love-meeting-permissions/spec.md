# Spec Delta

## Purpose

Кто может удалить встречу и кто может её покинуть, и как это обеспечивается на клиенте и на сервере.

## ADDED Requirements

### Requirement: Удалять может только создатель

Действие «Удалить» MUST быть доступно только создателю встречи; остальным участникам оно MUST NOT показываться,
а прямой вызов MUST отклоняться.

#### Scenario: Создатель удаляет встречу

- **WHEN** создатель удаляет постоянную встречу
- **THEN** встреча и связанная серия удаляются, живые сессии завершаются

#### Scenario: Участник не видит удаления

- **WHEN** участник (не создатель) открывает встречу
- **THEN** действия «Удалить» нет, доступно только «Покинуть»

### Requirement: Создатель не может покинуть встречу

Для создателя действие «Покинуть» MUST быть недоступно: закрыть встречу можно только удалением.

#### Scenario: Создатель ищет «Покинуть»

- **WHEN** создатель открывает встречу
- **THEN** «Покинуть» недоступно, «Удалить» доступно

#### Scenario: Серверная попытка

- **WHEN** клиент пытается убрать создателя из участников
- **THEN** сервер возвращает его обратно, встреча остаётся доступной создателю

### Requirement: Остальные только покидают

Участник, не являющийся создателем, MUST иметь только действие «Покинуть»; не-участник MUST NOT иметь ни удаления,
ни выхода.

#### Scenario: Участник покидает встречу

- **WHEN** участник нажимает «Покинуть»
- **THEN** он убирается из участников, встреча и её расписание не меняются

#### Scenario: Посторонний видит карточку

- **WHEN** пользователь, не входящий в участники, открывает встречу
- **THEN** ни «Удалить», ни «Покинуть» ему не предлагаются
