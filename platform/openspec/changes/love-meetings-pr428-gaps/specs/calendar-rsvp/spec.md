# Spec Delta

## Purpose

Ответы участников на события календаря (RSVP) и сводка ответов. Поведение принесено PR #428.

## ADDED Requirements

### Requirement: Ответ участника хранится в его копии события

Ответ MUST писаться в копию события у участника (`Event.rsvp`), для виртуального вхождения — через
обновление экземпляра серии. Мастер-событие ответов участников не хранит.

#### Scenario: Участник отвечает «буду»

- **WHEN** участник выбирает ответ на приглашение
- **THEN** ответ виден в его копии события, у остальных участников копия не меняется

### Requirement: Сводка ответов считается на мастере

Сводка (`Event.rsvpSummary`: сколько подтвердили, отказались, не ответили) MUST обновляться серверным
триггером на мастер-событии при любом ответе участника.

#### Scenario: Один из участников отказался

- **WHEN** участник отвечает «не буду»
- **THEN** сводка на мастере увеличивает число отказов на один

#### Scenario: Организатор не считается приглашённым

- **WHEN** панель события показывает «ожидают ответа»
- **THEN** организатор в это число не входит, даже если не отвечал
