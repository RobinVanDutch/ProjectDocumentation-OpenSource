# Spec Delta

## Purpose

Постоянная встреча (`PermanentMeeting`) — документ без расписания, сессия которой открывается любым входом.

## ADDED Requirements

### Requirement: Владелец постоянной встречи всегда остаётся участником

Система MUST NOT принимать правку `members` постоянной встречи, в которой нет ни одного из `owners`.
Правка отбрасывается сервером независимо от клиента, владелец остаётся участником.

#### Scenario: Из участников убирают владельца

- **WHEN** клиент отправляет обновление `members` без владельца встречи
- **THEN** обновление отклоняется, набор участников не меняется, в лог пишется причина

#### Scenario: Штатная правка участников

- **WHEN** владелец добавляет или убирает другого участника
- **THEN** правка применяется, владелец остаётся в списке

#### Scenario: Попытка в интерфейсе

- **WHEN** пользователь редактирует участников постоянной встречи в панели
- **THEN** убрать владельца из списка нельзя, сохранение такой правки недоступно

### Requirement: Язык транскрипции постоянной встречи берётся из интерфейса

Система MUST создавать постоянную встречу с языком комнаты, соответствующим языку интерфейса пользователя,
а не фиксированным `en`.

#### Scenario: Создание в русской локали

- **WHEN** пользователь с русским интерфейсом создаёт постоянную встречу
- **THEN** встреча создаётся с `language: 'ru'`

### Requirement: Гость постоянной встречи не видит режим «после»

`/guestInfo` MUST NOT отдавать гостю постоянной встречи режим `after`: постоянная встреча не заканчивается,
для неё допустимы только `before` и `live`.

#### Scenario: Гость постоянной встречи после завершения сессии

- **WHEN** сессия постоянной встречи завершена и гость открывает ссылку
- **THEN** лобби показывает состояние ожидания новой сессии, а не «встреча закончилась»
