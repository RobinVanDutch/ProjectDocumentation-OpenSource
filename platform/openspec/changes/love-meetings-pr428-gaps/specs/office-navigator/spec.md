# Spec Delta

## Purpose

Навигатор офиса: сегмент, который пользователь выбрал, и кнопки в шапке разделов.

## ADDED Requirements

### Requirement: Открытие документа во время звонка сохраняет сегмент навигатора

Переход к документу офиса (например, к протоколу встречи) MUST NOT переписывать первые сегменты маршрута: выбранный раздел навигатора остаётся тем же, а возврат назад возвращает пользователя в него.

#### Scenario: Протокол во время звонка

- **WHEN** пользователь во время звонка открывает протокол текущей встречи и возвращается назад
- **THEN** в навигаторе остаётся выбранным тот же раздел, из которого протокол открывали

#### Scenario: Переход из комнаты

- **WHEN** пользователь открывает документ из комнаты офиса
- **THEN** путь дополняется сегментом документа, ранее выбранный раздел не сбрасывается

### Requirement: В шапке раздела протоколов одна кнопка настроек

Секция протоколов в панели встречи MUST показывать одну кнопку настроек; дублирующая кнопка не выводится.

#### Scenario: Шапка секции протоколов

- **WHEN** пользователь открывает секцию протоколов в панели встречи
- **THEN** в шапке ровно одна кнопка настроек
