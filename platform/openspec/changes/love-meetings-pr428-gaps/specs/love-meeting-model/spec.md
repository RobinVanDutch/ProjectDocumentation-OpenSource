# Spec Delta

## Purpose

Модель встреч и её связь с серией, постоянной встречей и ссылкой. Модель остаётся такой, какой её задал
PR #428: этот change приводит к ней документацию и поведение, а не переписывает её.

## ADDED Requirements

### Requirement: Сессия связана с серией и с постоянной встречей

`MeetingMinutes` MUST ссылаться на серию через `eventId` миксина `MeetingEventLink` мастера, а на постоянную
встречу — через поле `meeting`. Отдельного поля расписания у сессии нет.

#### Scenario: Серия

- **WHEN** сессия открыта по вхождению серии
- **THEN** её `eventId` равен `eventId` мастера, `occurrence` — времени вхождения

#### Scenario: Постоянная встреча

- **WHEN** сессия открыта из постоянной встречи
- **THEN** у неё заполнен `meeting` и нет `occurrence`

### Requirement: `linkId` заполняется при выдаче ссылки

Модель PR объявляет `linkId` и описывает его как «shortId постоянной ссылки, отсутствует, пока ссылку
не выдали». Система MUST записывать этот shortId в документ при выдаче ссылки, чтобы поле и документация
совпадали с поведением.

#### Scenario: Ссылку выдали впервые

- **WHEN** участник впервые запрашивает ссылку на встречу
- **THEN** `linkId` содержит выданный shortId

#### Scenario: Ссылку отозвали

- **WHEN** ссылка отозвана и выдана новая
- **THEN** `linkId` содержит shortId новой ссылки
