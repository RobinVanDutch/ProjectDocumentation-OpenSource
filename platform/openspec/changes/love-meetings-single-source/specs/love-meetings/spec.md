# Spec Delta

## Purpose

Встреча хранится одним документом независимо от того, постоянная она или разовая, и попадает в списки
раздела «Встречи» и во вкладку «Группы». Планировщик показывает только те встречи, которые созданы в нём
самом. Дельта фиксирует требование владельца от 2026-11-24.

## ADDED Requirements

### Requirement: Списки раздела показывают все встречи

Таблица раздела «Встречи» MUST показывать все встречи пространства: постоянные, разовые и встречи без
серии (скрытые от календаря). Список MUST NOT строиться по календарным событиям.
Переключатель представлений раздела MUST остаться без изменений («Календарь / Таблица»).

#### Scenario: Разовая встреча, созданная из раздела

- **WHEN** пользователь создаёт разовую встречу в разделе «Встречи» и открывает таблицу
- **THEN** строка встречи присутствует в таблице с датой и участниками

#### Scenario: Встреча без серии

- **WHEN** встреча создана без календарной серии
- **THEN** она видна в таблице и отмечена иконкой «скрыта от календаря»

#### Scenario: Событие календаря

- **WHEN** в календаре есть событие без встречи
- **THEN** в таблице раздела «Встречи» его нет

### Requirement: Одна встреча — один документ

Создание разовой встречи MUST создавать `love.class.PermanentMeeting` с началом и длительностью и
MUST NOT создавать `calendar.class.Event`. Длительность MUST храниться в поле `duration`.
Постоянная встреча MUST хранить периодичность в `repeatEvery`.

#### Scenario: Разовая встреча

- **WHEN** пользователь создаёт разовую встречу
- **THEN** создан один документ встречи без `repeatEvery`, с `startDate` и `duration`

#### Scenario: Постоянная встреча

- **WHEN** пользователь создаёт постоянную встречу
- **THEN** создан документ встречи с `repeatEvery` и без календарной серии

### Requirement: Планировщик показывает только свои события

Встречи, созданные в разделе «Встречи», MUST NOT появляться в планировщике. Серия календаря MUST
создаваться только при создании встречи в планировщике.

#### Scenario: Встреча из раздела не видна в планировщике

- **WHEN** встреча создана в разделе «Встречи»
- **THEN** в планировщике нет ни события, ни вхождения этой встречи

#### Scenario: Встреча из планировщика

- **WHEN** пользователь создаёт встречу в планировщике
- **THEN** событие видно в планировщике, а встреча — в списках раздела

### Requirement: Существующие встречи-события переносятся

Миграция MUST создавать документ встречи для каждого календарного события с миксином встречи, у которого
нет ссылки на встречу. Миграция MUST быть идемпотентной и MUST NOT удалять события и серии.

#### Scenario: Повторный запуск миграции

- **WHEN** миграция запускается второй раз
- **THEN** дубли встреч не создаются, ссылки в миксинах остаются корректными

### Requirement: Вкладка «Группы»

Вкладка «Группы» MUST показывать встречи, разбитые по группам, и MUST NOT менять состав строк по
сравнению с разделом «Встречи». Создание встречи с этой вкладки MUST NOT предлагаться.

#### Scenario: Встречи без группы

- **WHEN** у части встреч группы нет
- **THEN** они идут последней секцией, остальные — по своим группам
