# Spec Delta

## Purpose

Навигатор офиса должен вести к одному разделу встреч с переключателем представления, а вместо отдельной
вкладки «Постоянные встречи» появляется вкладка «Группы» с тремя наборами строк. Дельта фиксирует
решения владельца от 2026-11-20 (Р1, Р2): «оптимизируем расположение» - список и таблица переезжают
в раздел «Встречи», а «Группы» показывают обычные встречи, постоянные встречи и встречи без отображения.

## ADDED Requirements

### Requirement: Раздел «Встречи» с выбором представления

Раздел «Встречи» MUST показывать календарь и MUST давать переключатель «Календарь / Список встреч /
Таблица встреч». Список и таблица MUST быть теми же представлениями, что раньше были на странице
«Постоянные встречи». Выбранное представление MUST сохраняться для пользователя.

#### Scenario: Переключение на список

- **WHEN** пользователь открывает раздел «Встречи» и выбирает «Список встреч»
- **THEN** встречи показаны списком; повторный вход в раздел открывает список, а не календарь

#### Scenario: Переключение на таблицу

- **WHEN** пользователь выбирает «Таблица встреч»
- **THEN** видны те же колонки, что были на странице постоянных встреч (следующее вхождение,
  участники, последняя сессия), и работают группировка и сортировка

#### Scenario: В разделе нет постоянных встреч

- **WHEN** в пространстве есть только серии календаря
- **THEN** все три представления работают без пустых экранов и без ошибок

### Requirement: Вкладка «Группы» вместо вкладки «Постоянные встречи»

Пункт навигатора «Постоянные встречи» MUST быть заменён пунктом «Группы». Вкладка MUST показывать три
набора строк: обычные встречи (не постоянные), постоянные встречи, встречи без отображения - те, что не
показываются в календаре и планировщике. Внутри вкладки строки MUST быть разбиты по группам; встречи без
группы MUST идти последней секцией.

#### Scenario: Встречи без отображения

- **WHEN** существует постоянная встреча, созданная без календарной серии (не показывается в календаре
  и планировщике)
- **THEN** она видна во вкладке «Группы» в наборе «Встречи без отображения» и не видна в календаре

#### Scenario: Группа с разными типами встреч

- **WHEN** в группу добавлены обычная встреча и постоянная встреча
- **THEN** обе видны в секции этой группы с признаком типа; переход открывает карточку
  соответствующего класса

#### Scenario: Пустая группа

- **WHEN** все встречи группы удалены или перенесены
- **THEN** секция группы показывает пустое состояние с действием «Новая встреча в группе»; ошибок нет

#### Scenario: Старая ссылка на раздел

- **WHEN** пользователь открывает ранее сохранённый адрес `/love/permanent`
- **THEN** он попадает во вкладку «Группы» (или получает понятное пустое состояние), а не 404
