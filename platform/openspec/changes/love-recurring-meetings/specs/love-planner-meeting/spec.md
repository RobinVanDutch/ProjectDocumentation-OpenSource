# Spec Delta

## Purpose

Создание встречи из планировщика и из формы события: комната, участники, постоянная встреча, промежуток
повторения и связь записи планировщика с постоянной встречей.

## ADDED Requirements

### Requirement: Форма события позволяет сделать встречу постоянной

Форма создания события MUST позволять сделать встречу постоянной, выбрав участников и промежуток, не покидая форму.
Включённый переключатель создаёт `PermanentMeeting` с выбранными участниками и промежутком и связывает его с мастером
серии через `MeetingEventLink.permanentMeeting`.

#### Scenario: Событие становится постоянной встречей

- **WHEN** пользователь включает «Сделать постоянной» при создании события с комнатой
- **THEN** создаются серия, мастер с миксином `MeetingEventLink` и постоянная встреча с выбранными участниками
  и промежутком; мастер ссылается на неё в `permanentMeeting`

#### Scenario: Переключатель выключен

- **WHEN** переключатель не включён
- **THEN** создаётся только встреча-серия, постоянной встречи нет

### Requirement: Промежуток повторения хранится на постоянной встрече

`PermanentMeeting` MUST хранить промежуток, через который встреча ставится постоянно, в необязательном поле
`repeatEvery` (миллисекунды). В планировщике значение по умолчанию берётся из `Schedule.meetingInterval`.

#### Scenario: Запись из планировщика

- **WHEN** постоянная встреча создаётся из планировщика с `meetingInterval` 30 минут
- **THEN** `repeatEvery` постоянной встречи равен 30 минутам

#### Scenario: Промежуток не задан

- **WHEN** пользователь не задал промежуток
- **THEN** поле не заполняется, встреча работает как обычная постоянная встреча

### Requirement: Постоянную встречу можно создать из планировщика

Диалог создания записи планировщика (`calendar.class.Schedule`) MUST предлагать создание постоянной встречи:
пользователь выбирает участников и промежуток, а комната берётся из уже существующего выбора комнаты. По подтверждению
создаётся постоянная встреча с выбранными участниками и промежутком.

#### Scenario: Запись планировщика с постоянной встречей

- **WHEN** пользователь создаёт запись планировщика и включает «Постоянная встреча»
- **THEN** создаются запись планировщика и постоянная встреча с выбранными участниками и промежутком

#### Scenario: Обычная запись планировщика

- **WHEN** переключатель выключен
- **THEN** создаётся только запись планировщика с комнатой, как раньше, — постоянной встречи нет

### Requirement: Встреча из планировщика становится серией событий

Встреча, созданная из планировщика, MUST создаваться как серия событий с миксином `MeetingEventLink` на мастере,
а не как один документ `Schedule`: только так у неё есть `eventId` для сессий, ссылки и бейджа.

#### Scenario: Встреча из планировщика попадает в календарь

- **WHEN** запись планировщика создана с включённой встречей
- **THEN** в календаре появляется серия с миксином `MeetingEventLink`, её вхождения видны на тех же днях,
  что и запись планировщика

### Requirement: Запись планировщика связана с постоянной встречей

Связь записи планировщика с созданной постоянной встречей MUST храниться в `MeetingSchedule.meetingId`, чтобы встреча
не терялась при повторном открытии записи.

#### Scenario: Открыли запись планировщика после создания

- **WHEN** пользователь открывает запись, из которой создана постоянная встреча
- **THEN** запись показывает, что встреча постоянная, и позволяет перейти к ней

#### Scenario: Повторное сохранение записи

- **WHEN** пользователь сохраняет уже созданную запись ещё раз
- **THEN** вторая постоянная встреча не создаётся
